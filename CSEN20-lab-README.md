# scu-CSEN20-lab

Lab work for CSEN 20 / CSEN 20L (Embedded Systems) at Santa Clara University, 2026.
Programs are written in ARM Assembly and C.

## Labs

Each lab is in its own workspace folder under `scu-CSEN20-lab/`. My code is in each
workspace's `src/` folder; the `Main.c` files and the files in `inc/` came with the course.

- **Lab 1A — 16-bit calculator** — `workspace1/src/Lab1A-Calculator.s`
- **Lab 2A — 8-bit binary numbers** — `workspace2/src/Lab2A-Implementation-1.c`
- **Lab 3A — functions and parameters** — `workspace3/src/Lab3A-Implementation.s`
- **Lab 4A — copying data quickly** — `workspace4/src/Lab4A-Implementation.s`
- **Lab 5D — automobile tire sizes** — `workspace5/src/Lab5D-Implementation.s`
- **Lab 6D — Towers of Hanoi** — `workspace6/src/Lab6D-Implementation.s`

Each workspace also contains the course library and build files (`library.a`,
`linker.ld`, `makefile`) used to build and run the labs.
